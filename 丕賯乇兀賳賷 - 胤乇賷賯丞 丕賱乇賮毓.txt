حساباتي — إزاي ترفعه وتثبّته كتطبيق على الموبايل
====================================================

الفولدر ده فيه كل اللي محتاجه:
  index.html             ← السيستم نفسه
  manifest.webmanifest   ← بيعرّف المتصفح إنه تطبيق (الاسم والأيقونة)
  sw.js                  ← بيخلّيه يفتح من غير نت
  icon-*.png / favicon   ← الأيقونات

مهم: اللي بيترفع هو الصفحة بس. بياناتك (المصروفات والخزن والديون...) بتفضل
متخزنة جوه موبايلك/متصفحك، ومحدش بيشوفها — ولا حتى GitHub.


الرفع على GitHub Pages (مجاني — مرة واحدة بس)
---------------------------------------------
1) اعمل حساب على github.com (لو مش عندك).
2) اضغط "+" فوق ← New repository
   - الاسم: hesabaty
   - اختار Public  (الكود بس اللي هيبقى عام — بياناتك لأ)
   - Create repository
3) في الصفحة اللي هتفتح اضغط "uploading an existing file"
   واسحب كل الملفات اللي جوه الفولدر ده (الملفات نفسها مش الفولدر) ← Commit changes
4) روح Settings ← Pages
   - Source: Deploy from a branch
   - Branch: main  و  / (root)  ← Save
5) استنى دقيقة أو اتنين، وهيظهر الرابط بالشكل ده:
   https://اسم-حسابك.github.io/hesabaty/


تثبيته على الموبايل
-------------------
أندرويد (كروم):
  افتح الرابط ← هيظهرلك "تثبيت التطبيق"، أو من قايمة ⋮ ← "تثبيت التطبيق"
  (أو من جوه السيستم: الإعدادات ← "📲 ثبّت حساباتي على الشاشة الرئيسية")

آيفون (لازم Safari):
  افتح الرابط ← زرار المشاركة ⬆️ ← "إضافة إلى الشاشة الرئيسية"

بعدها هيبقى ليه أيقونة، ويفتح شاشة كاملة، ويشتغل من غير نت.


نقل بياناتك من النسخة القديمة
-----------------------------
البيانات اللي سجلتها في الملف القديم مش هتنتقل لوحدها (المتصفح بيعتبر الرابط
الجديد مكان تاني). عشان تنقلها:
  1) افتح النسخة القديمة ← الإعدادات ← "تنزيل نسخة احتياطية"
  2) افتح التطبيق الجديد ← الإعدادات ← "استرجاع من نسخة" ← اختار الملف


لما أبعتلك تحديث
-----------------
ادخل على الـ repository ← Add file ← Upload files ← ارفع index.html الجديد
مكان القديم ← Commit. التطبيق هيجيب التحديث لوحده أول ما يفتح وفيه نت،
وبياناتك مش هتتأثر.


نصيحة
-----
من الإعدادات اضغط "📤 شارك النسخة" وابعتها لنفسك على واتساب أو احفظها في
Google Drive مرة في الأسبوع — السيستم هيفكرك لو نسيت.
